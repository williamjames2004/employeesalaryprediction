Predict My Salary Explore Project

About the Project

A machine learning application for exploring employee salary estimates.

Project Objective

Estimate employee salary from available career attributes and learn how regression models identify relationships in historical data.

Employee Profile

The input profile includes age, gender, education level, job title, and years of professional experience.

Prediction System

A saved Scikit-learn pipeline processes the employee details and produces a continuous salary estimate.

Important: The prediction depends on the quality, size, currency, and coverage of your training dataset. It is an estimate, not a guaranteed salary offer or professional compensation assessment.

Dataset Column Details

The input columns are used to predict the target column, Salary.

Column Name Data Type Description Role
Age Numeric Employee's age in years. Input
Gender Categorical Gender category recorded in the dataset. Input
Education Level Categorical Highest recorded education level, such as Bachelor's, Master's, or PhD. Input
Job Title Categorical Employee's job role, such as Software Engineer or Data Analyst. Input
Years of Experience Numeric Number of years of work experience. Input
Salary Numeric The recorded salary value the model learns to predict. Target

The dataset's salary currency and whether the values are annual or monthly must be confirmed from the original data source.

Algorithm Details

Gradient Boosting Regression learns by combining a sequence of decision trees.

1Data Preprocessing

Missing categorical values are filled using the most frequent value. Missing numerical values are filled using the median. One-hot encoding converts categorical columns into numerical features that the model can process.

2Gradient Boosting

The model builds decision trees sequentially. Each new tree attempts to improve the existing model by learning patterns in its remaining errors.

3Model Evaluation

Mean Absolute Error (MAE) measures the average absolute difference between actual and predicted salaries. R² is also reported when the test target has sufficient variation.

4Prediction

After evaluation, the pipeline is trained on all valid records and saved as a pickle model file. Flask loads this file to estimate salaries for new employee profiles.

Sample Questions and Answers

Understand the expected inputs and the limits of the prediction.

What does the model predict?

It predicts a numerical salary estimate using age, gender, education level, job title, and years of experience.

Why is Gradient Boosting used?

Gradient Boosting combines multiple decision trees in sequence to learn patterns and reduce prediction errors on suitable datasets.

What if I enter a new job title?

The encoder is configured to handle previously unseen categories. However, a new job title may not have enough learned examples for a reliable salary estimate.

Is the estimate always accurate?

No. Accuracy depends on dataset size, data quality, representation of job roles, and how well the training records match the employee being evaluated.

What is MAE?

Mean Absolute Error is the average absolute difference between predicted and actual salary values. It is expressed in the same units as the salary target.

Can I use this for a real salary negotiation?

Treat it as an educational demonstration, not a definitive compensation benchmark. Compare reliable local salary surveys, responsibilities, location, and benefits too.
